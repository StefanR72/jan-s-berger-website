So lädst du die richtigen Berichte bei Amazon herunter
  1. Öffne KDP-Berichte und melde dich an.
  2. Wähle im Dashboard den Zeitraum und tippe auf das Download-Symbol rechts neben dem Zeitraum (Excel-Datei).
  3. Öffne hier Bericht importieren und wähle die heruntergeladene Excel-Datei aus.
  4. Der komplette Dashboard-Export enthält Verkäufe, Vorbestellungen (soweit abgerechnet), Tantiemen und Kindle-Unlimited-Seiten in einer Datei.

Jede neu importierte Datei ersetzt nur den entsprechenden Berichtsbereich. Überschneidende Exporte werden nicht zusammenaddiert. Vorbestellungen werden separat angezeigt und nicht zu abgeschlossenen Bestellungen addiert.

Datenschutz: Dateien werden ausschließlich lokal in deinem Browser ausgewertet. Es werden keine Zahlen an einen Server übermittelt. Für den bequemen Zugriff merkt sich dieses Gerät die zuletzt importierten Summen im lokalen Browser-Speicher. Bei Löschung der Browserdaten gehen sie verloren.

Hinweis: Inoffizielles, unabhängiges Tool. Keine Amazon-API-Verbindung. Tantiemen sind Schätzungen aus dem importierten Bericht, keine Zahlungsgarantie. Unterschiedliche Währungen werden nicht ungeprüft addiert. Diese Version wurde mit einem deutschsprachigen Original-KDP-Dashboard-Export getestet. Andere Berichtstypen können abweichende Spalten enthalten.
